# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

**DO NOT** open a public GitHub issue for security vulnerabilities.

Instead, please email: [security@onlyfunpeople.com.ar](mailto:security@onlyfunpeople.com.ar)

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Response

- We will acknowledge receipt within 48 hours
- We will provide a timeline for the fix
- We will credit reporters (unless anonymity is requested)

## Scope

This policy applies to all projects under the OnlyFunPeopleStudios organization.

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest  | Yes       |
| < Latest | No       |
